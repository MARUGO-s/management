# 貸借合計カードのフード・飲料内訳（2026-11-12）

## 変更

店舗別貸借り合計の総貸出金額／総借入金額カードに、フード・飲料の内訳を表示する。既存の分類関数を再利用し、未分類の金額は「その他」（非ゼロ時のみ）として残す。両主要区分は0円でも表示する。

店舗・期間・修正相殺・M-martの貸借向きは、既存集計が確定した明細に従う。既存の総額・残高・CSV・元データ・入力・認証・送信payload・受付ID・GAS・バックエンドを変更しない。食材を「フード」として表示し、分類ロジックそのものの再設計はしない。
